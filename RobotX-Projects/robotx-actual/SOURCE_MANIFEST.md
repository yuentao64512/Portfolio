# RobotX actual control-stack source

This is a GitHub-safe source snapshot collected from the USV Orin NX at:

`/home/usv-pixhawk/Desktop/dm3/MASTER_SCRIPTS`

The snapshot contains the shared `optiprimex` package—including its UAV, USV and OCS modules—plus the USV UI, common launch scripts, profiles, tests and the complete `robotx-uav-robocommand` source tree.

Runtime logs, virtual environments, Python caches, nested Git metadata, generated archives, network environment files, keys and credentials are intentionally excluded. Hardware motion and mission execution were not started while creating this snapshot.
