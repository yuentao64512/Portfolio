# RobotX simulation asset manifest

This folder is the GitHub-safe source snapshot of `/home/robotx/usv_sim_workspace` on the RTX 5060 workstation.

Included are the Gazebo worlds and models, ASV wave-simulation source, navigation-beacon plugin source, OCS/robocommand integration, boat and drone control scripts, launchers, configuration files, tests, and project documentation.

The following machine-generated or unsuitable files remain on the 5060 and are intentionally not committed:

- Git metadata from the original and nested repositories.
- ROS/Gazebo `build`, `install`, `log`, and compiled-library outputs.
- Runtime locks, logs, caches, JSONL telemetry, and saved world state.
- Timestamped backup/staging copies and duplicate prototype archives.
- Extracted firmware binaries and parameter dumps.
- Environment files or credentials, if later created.

Rebuild generated components on the target machine using the scripts and instructions in this folder.
