Executive summary

This project detects five human actions: falling_down, lying_down, walking, standing, and sitting. The pose detector extracts body keypoints; a separate action head classifies a 12-frame temporal window. The final selected action head is a balanced Random Forest.

Grouped hold-out result: 73.5% accuracy and 0.732 macro F1.

Important scope: this is a research prototype for action classification, not a medical fall detector or emergency-response system. The bird’s-eye DJI recording is used in this report for visual examples only; it was not included in the current training dataset.

2. How the data is cleaned and sorted

  1. Source separation: public GMDCSA24 data and local user recordings are kept identifiable by source, subject/file group, and segment ID.
  2. Temporal annotation: the six local recordings are split into short labeled time ranges rather than assigning one label to an entire recording. This captures transitions such as standing-to-sitting and standing-to-floor.
  3. Frame sampling: 12 timestamps are sampled from each labeled interval.
  4. Pose extraction: YOLO11n-pose extracts 17 COCO keypoints. The largest detected person is selected for each frame because the current user setup is single-person.
  5. Normalization: keypoints are normalized to image width/height, centered around the hip, and scaled relative to the torso so the classifier focuses on posture and motion rather than pixel location.
  6. Quality recording: detection rate is saved for each user sequence. The current average user pose detection rate was 82.9%.
  7. Label filtering: only the five target labels are passed to the action head. Unknown labels are excluded.
  8. Leakage control: train/test splitting is grouped by source video/subject/file group, so nearby windows from the same recording do not appear in both train and test.
Current limitation in cleaning: low-detection sequences are recorded but not automatically discarded. A priority improvement is to review or reject sequences below a chosen detection-rate threshold and recheck ambiguous transition labels.

4. Training process

Video segments → 12 sampled frames → YOLO11n-pose keypoints → hip/torso normalization → temporal pose features → grouped train/test split → Logistic Regression and Random Forest comparison → final Random Forest refit → models/actions.pkl
  1. YOLO11n-pose produces 17 body keypoints per frame.
  2. The action feature extractor uses normalized pose, pose statistics, final pose, velocity, confidence/visibility, body orientation, and hip motion.
  3. The system compares a Logistic Regression baseline with a Random Forest action head.
  4. The test split is held out by source group and uses random_state=42.
  5. The better model is then refit on all available training sequences, including the falling-only augmentation.
  6. Runtime maintains a temporal buffer for each tracked person and smooths probabilities to reduce label flicker.

SuccessThe predicted action matches the reviewed segment label on a held-out sequence, with useful confidence and stable temporal behavior.A held-out sitting window is predicted as sitting; a held-out falling window is predicted as falling_down.
Failure: class confusionThe action is recognized as a neighboring posture or motion.Walking predicted as standing, or lying_down predicted as falling_down.
Failure: missed poseThe detector misses the person or keypoints, so the action head receives weak/zero evidence.Person is partly outside the camera view or occluded.
Failure: domain shiftThe camera, environment, distance, lighting, clothing, or number of people differs from training.Outdoor/drone footage or a crowded scene when most training footage is indoor and single-person.

8. Main challenges and their effects

Indoor versus outdoor data

Yes, it can affect performance. Indoor footage has different backgrounds, lighting, floor geometry, camera height, clothing, and distance from the person. A model trained mostly indoors may learn shortcuts or encounter weaker pose detections outdoors. The bird’s-eye viewpoint also changes the apparent geometry of standing, walking, and falling. The current public dataset is mostly indoor and the user recordings are bedroom-based; outdoor/aerial performance is therefore not established.

Small and correlated dataset

The total of 358 sequences is modest for five actions, and many sequences come from the same people and videos. Twelve frames per sequence do not equal twelve independent examples. This can make the reported score optimistic for new people or new locations even though grouped splitting reduces direct leakage.

Ambiguous actions

Falling_down, lying_down, floor sitting, kneeling, and deliberate lowering can look similar in a single frame. Motion and temporal context are necessary. Standing and walking also overlap when a person is captured mid-step or nearly still.

Pose detector quality

The local user pose extraction averaged 82.9% valid detection rate. Missed keypoints, partial visibility, and people near the image boundary can directly reduce classifier accuracy.

10. What the results suggest and the decision

The Random Forest is the better of the tested action heads, improving accuracy by 3.9 percentage points over Logistic Regression. Sitting is currently the strongest class; walking and standing are the weakest pair. Falling_down recall is 0.810 on the grouped test split, but this is not sufficient evidence for safety-critical deployment.

Decision: keep the Random Forest as the current research baseline, keep the bird’s-eye DJI video as report-only until it is deliberately annotated and added to a controlled training/evaluation split, and prioritize new diverse recordings before claiming robust real-world fall detection.
